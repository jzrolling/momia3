# 高精度高速实例分割与端到端中线预测：设计笔记

状态：头脑风暴与候选方案，尚未纳入 momia3 默认实现。

## 1. 目标与现状

目标是在保持细菌实例分割、接触细胞分离和亚像素轮廓质量的同时，减少 OmniPose 推理中固定 200 步 Euler 积分及逐实例 midline 后处理的成本。

当前链路为：图像 → 流场/距离场/边界场 → Euler 汇聚与实例重建 → outline → pole/skeleton/geodesic/spline midline。训练中的短程可微积分用于约束流场，推理中的长程积分用于得到实例，两者不可互相替代。

## 2. 跳出迭代流场的候选方向

### 2.1 SinkMap：直接预测最终汇聚坐标

网络对前景像素直接预测所属细胞的中心或汇聚坐标，同时输出前景、接触边界和中心热度。推理由“一次偏移预测 + 中心投票/空间分配”取代固定 200 步积分。

优点是结构简单、可复用现有实例 mask 和主干网络。难点是相邻细胞之间汇聚坐标不连续，以及长细胞需要较大的有效感受野。这是近期最适合做原型的方向。

### 2.2 SpineField：中心线—半径表达

将细菌表示为弯曲中心线及沿中心线变化的半径，而不是围绕单一中心的星凸形状。网络学习中心线、端点、像素到中心线的归属和局部半径。适合长、弯曲和形态变化大的细菌，但中心线交叉、断裂和分支处理更复杂。

### 2.3 Affinity Graph：学习实例连接关系

预测局部或长程像素边是否属于同一实例，再通过连通域或快速近似图划分得到实例。它直接监督接触处“连接或切断”，但全局 multicut 不宜作为高速默认后端。

### 2.4 参数化细胞集合预测

网络直接输出每个细胞的中心、Bézier 中心线、宽度曲线和轮廓残差，一次得到矢量几何。长期表达能力强，但需要更复杂的集合匹配训练，在当前小规模数据上更容易过拟合。

## 3. Euler 的替代与保留价值

保持原递推并进行收敛提前退出、直接 gather 和减少临时张量，是最低风险的加速。粗到精积分、successor graph/pointer jumping、RK2/RK4 都可能减少计算，但会改变汇聚数值或引入环、误合并等问题，需要独立验证。

## 4. momia3 midline 提供的监督

现有 `ops/midline.py` 能从实例几何生成：

- 无序极点对及亚像素极点坐标；
- 测地中心线或 SDF skeleton 主干；
- 平滑样条与固定点数重采样；
- 切线、宽度 profile、分支和质量标志。

因此可以从已有 mask 自动生成 midline 训练目标，无需先增加全部人工标注。不过这些是算法伪标签，必须保留质量权重，并对极点、隔膜和弯曲细胞建立人工核查子集。

## 5. 推荐整合：PoleField / ArcField 多任务场

### 5.1 联合输出

保留 OmniPose 的 `flow_y, flow_x, distance, boundary`，增加：

- `midline`：中线概率；
- `poles`：无序极点热度，并为局部偏移分支保留亚像素精度；
- `arc`：每个前景像素对应中线归一化弧长位置 `s∈[0,1]`；
- `tangent`：用 `(sin(2θ), cos(2θ))` 表示无方向轴线，避免极点互换和角度跳变；
- 可选 `radius/width`：局部半宽或宽度。

这仍是单次网络前向。实例归属由流场给出，midline 和极点不再从 skeleton 图搜索获得。

### 5.2 从伪标签构造 arc 目标

对每个训练实例运行现有 midline 提取器，将中线按弧长归一化到 `[0,1]`。把每个前景像素投影到最近的中线位置，得到稠密 arc 坐标。极点的两端顺序可任意选择，通过交换不变损失处理。

### 5.3 直接中线解码

在每个实例内，对固定弧长节点 `u_k` 计算预测中线像素的加权坐标平均：

`c_k = Σ_p w_k(p) p / Σ_p w_k(p)`，其中 `w_k` 同时依赖 midline 概率和 `arc(p)` 与 `u_k` 的接近程度。

这样可直接得到固定 K 点中线，无需逐实例 Dijkstra 或 skeleton 最长路径。两个端点由极点热度和局部偏移独立解码，再与轮廓相交约束结合，避免弧长平均把端点拉离细胞尖端。

### 5.4 几何一致性损失

除各场监督外，可加入：

- 中线必须落在对应实例前景内；
- 极点必须接近实例边界，且同一实例恰好两个；
- 中线切线与距离场梯度近似垂直；
- 中线处距离场近似为局部 ridge，距离值与半宽一致；
- 中线和极点的实例归属必须与流场分割一致；
- 极点交换不变损失，以及低质量伪标签的置信度加权。

这些约束让分割与中线相互监督：接触边界帮助中线归属，双极点和合理中线又反向抑制细胞粘连。

## 6. “端到端”的边界

推荐方案是端到端的多任务场学习和一次几何解码，不要求最终离散实例分配也可微。强行把聚类、连通域和最短路径全部做成可微模块，通常会显著增加训练成本，未必改善最终几何。

若后续需要更直接的图像到曲线预测，可在中心/实例 proposal 后增加 per-instance curve head，直接输出 K 个样条控制点和两个极点。这是第二阶段方案，不建议作为第一个原型。

## 7. 建议实验顺序

1. 先仅增加 midline + poles + tangent，验证多任务监督能否提高分割与极点精度。
2. 增加 arc，并用固定节点加权解码替代 skeleton/geodesic midline。
3. 比较“原版 OmniPose + 当前 midline”与“联合场 + 直接解码”的实例 F1、轮廓 IoU、极点误差、中线误差和全链路耗时。
4. 若 Euler 仍是主要瓶颈，再让同一几何 decoder 与 SinkMap 共用实例中心，而不是一开始就替换全部分割框架。

关键风险是伪标签质量、长弯曲细胞的 arc 投影歧义、分枝细胞不满足双极点先验，以及相邻实例的场混合。原型应保留现有 midline 作为 QC 和回退，而不是立即替换。

## 8. 借鉴高速姿态检测与骨架重建

### 8.1 问题对应关系

固定点数的 midline 可以视为一个有序的单细胞姿态：两个极点是特殊关键点，中间点是按弧长排列的骨架关键点，点间边由中心线拓扑给出。因此可以借鉴人体、动物和植物表型中的关键点检测、关联和坐标解码，而不必从 skeleton 图搜索开始。

### 8.2 Top-down：实例后接姿态头

先用实例分割得到细胞 ROI，再用批量姿态头预测 K 个有序 midline 点和两个极点。HRNet/高分辨率特征、heatmap + soft-argmax、局部亚像素偏移或 SimCC 一维坐标分类都可使用。

这一路线研发风险最低，适合作为 ArcField 的强对照。它需要逐实例 ROI，但可将所有细胞批量送入同一个轻量姿态头；与逐实例 Dijkstra 相比仍可能更快。SimCC 将横纵坐标分别作为离散分类，可通过细分 bin 达到亚像素定位；soft-argmax 则保留可微坐标期望。

### 8.3 Bottom-up：全图关键点和关联场

一次性检测所有细胞的极点和弧长关键点，再用 Part Affinity Fields、 associative embedding、切线场或 ArcField 将它们分配到实例并连接成曲线。这与 OpenPose/HigherHRNet/DEKR 的多实例姿态问题相似。

优点是全图一次前向，更符合统一几何场的论文故事；难点是相邻细胞的同名关键点关联、遮挡和密集峰值。ArcField 可以被理解为一种面向单轴细胞的连续关联坐标，而 PAF/切线场可补充点间连通约束。

### 8.4 骨架重建模型的可借鉴组件

可借用高分辨率主干、关键点不确定性、可见性/质量分支、分布式坐标编码、时序一致性和结构损失，但不必直接采用大型人体姿态 Transformer。细菌 midline 的关键区别是：形状来自实例轮廓，极点与生物学语义相关，且分枝细胞可能破坏固定双极点拓扑。

## 9. 是否仍需从头训练

不需要把从头训练作为新方法的默认方案。当前从头训练模型仍有价值：它们提供优化流程、数据划分和架构能力的受控基线，也用于区分“方法收益”和“预训练收益”。但最终模型应优先测试预训练初始化和微调。

Cellpose-SAM 已证明通用 SAM 视觉编码器可以适配 Cellpose 流场并获得很强的细胞分割泛化能力。它说明通用表征对细胞图像有迁移价值，但不能直接推出其适合 momia3 的高速目标：SAM 编码器参数量和计算量远大于 CPnet/AttResUNet，且通用图像与相差细菌图像仍有域差异。

预训练主要改善数据效率、收敛和泛化，不会自动提升推理速度。高精度极点定位还需要高分辨率 decoder 和局部几何监督，不能只使用低分辨率语义 embedding。

### 9.1 建议的初始化层级

1. 保留 CPnet 和 AttResUNet 从头训练结果作为基线。
2. 测试轻量 ImageNet 预训练 CNN encoder + 自定义几何 decoder，作为速度友好的迁移方案。
3. 测试 DINO/MAE/SAM ViT 或 Cellpose-SAM 微调，作为泛化与质量上限。
4. 若已有大量未标注的细菌时序图像，优先探索小型编码器的领域自监督预训练，再微调几何场。这可能比直接部署大型 SAM 更符合高速目标。

对小型定制 encoder 推荐先低学习率全量微调，而不是长期冻结。灰度复制到三通道或适配首层即可；冻结只适合快速验证特征是否有用。

## 10. 修订后的研发策略

第一条实验线采用 top-down 姿态基线：现有实例分割 + 轻量高分辨率姿态头 + K 点 midline/极点，快速验证监督标签和坐标精度。

第二条实验线采用统一 bottom-up 几何场：OmniPose 实例场 + midline/poles/tangent/arc，并与 PAF 或关联约束结合。这是主要创新候选。

两条线都应比较从头训练、轻量预训练 encoder 和较强 foundation encoder。最终选择需同时考虑精度、外部泛化、训练成本、2048×2048 全链路速度和显存，而不是仅比较验证 loss。

## 12. 执行框架（待评审，不代表已批准实施）

### 12.1 总体原则

1. 当前从头训练的原版 OmniPose recipe 实验继续作为受控基线，不中断、不改配置。
2. 新方法先验证几何表示是否成立，再扩大训练规模；避免同时更换 backbone、损失、数据和解码器。
3. 所有模型使用相同的 group-aware 数据划分和独立测试集；新增模型不能使用旧测试组训练或调参。
4. 分割、midline、极点和全链路速度分别评估，不能用单一 F1 或网络前向时间代表整体性能。
5. 新功能先作为 momia3 可选后端，超过基线并通过回归验证后再考虑默认启用。

### 12.2 阶段 A：冻结基线与建立几何评测集

任务：

- 整理原版 CPnet、从头训练 CPnet/AttResUNet、原版 recipe 重训模型的统一预测和指标。
- 固定训练、验证、测试及外部数据清单，记录图像、mask、ROI 和处理代码版本。
- 从不同菌种、成像条件、细胞长度、弯曲程度和密度中选取独立细胞，人工校正 midline 与两个极点。
- 明确几何尖端、生物学极点和隔膜位置的标注规范；记录不确定或不可用实例。
- 为 momia3 自动生成的 midline 伪标签增加质量等级和置信度权重。

产物：

- 冻结的 baseline manifest 和统一评估脚本。
- 独立人工几何测试集，建议先覆盖 500–1000 个细胞。
- 数据 QC 报告及伪标签可用性分层。

继续条件：测试集标注规范可重复，主要形态均有覆盖，伪标签质量能够被可靠分层。若这一条件不满足，暂停扩大模型训练。

### 12.3 阶段 B：Top-down 姿态基线

目标：用最小研发风险验证“固定 K 点 midline + 双极点”是否能达到或超过当前几何流程。

任务：

- 使用冻结的实例分割结果生成 ROI，训练轻量高分辨率姿态头。
- 输出 K 个有序 midline 点、两个极点、可见性/不确定性和质量分数。
- 对比 heatmap + soft-argmax 与一种亚像素坐标方案；SimCC 可作为坐标分类候选。
- 所有细胞 ROI 批量推理，保留现有 momia3 midline 作为异常回退。

对照：当前 momia3 spline/equidistant midline，以及直接坐标回归。

指标：对称 Chamfer/Hausdorff、中线覆盖与偏移、极点 median/P95 误差、宽度 profile 误差、失败率、每细胞和每视野耗时。

继续条件：在人工测试集上达到当前几何流程的精度，并展示批量推理或稳定性的实际优势。若仅拟合伪标签而在人工数据上失败，先修正标签和表示，不进入复杂 bottom-up 开发。

### 12.4 阶段 C：Bottom-up PoleField / ArcField 原型

目标：验证单次全图前向能否同时支持实例分割与直接中线解码。

任务：

- 在同一主干上保留 OmniPose 实例场，依次增加 midline/poles/tangent、arc 和几何一致性损失。
- 构造交换不变的极点监督、单调弧长监督和实例内部约束。
- 实现固定节点加权曲线解码、独立极点解码和异常检测。
- 用 PAF/切线或 associative embedding 解决相邻细胞同名关键点关联；只在确有需要时增加复杂度。
- 对高曲率、分枝、粘连和越界细胞保留质量门控与经典几何回退。

消融顺序：实例场基线 → +midline/poles/tangent → +arc 直接解码 → +几何一致性 → 必要时 +关联场。

继续条件：ArcField 在人工几何测试集上具有可信精度，且相对 top-down 或经典流程体现全图吞吐优势；同时实例分割不能明显退化。若 arc 学习不稳定或高曲率解码系统性失败，则保留 top-down 姿态方案，不强行推广 bottom-up。

### 12.5 阶段 D：预训练与效率选择

目标：分离架构、预训练和数据规模的贡献，选择满足精度要求的最小模型。

顺序而非全组合穷举：

1. 当前最佳从头训练小型模型。
2. 轻量 ImageNet 预训练 CNN encoder + 相同几何 decoder。
3. 一个较强 foundation encoder（Cellpose-SAM 或 DINO/MAE/SAM 类）作为质量与泛化上限。
4. 若未标注细菌图像充足，再进行小型 encoder 的领域自监督预训练。

微调策略：先验证冻结特征的快速可行性，再以较小学习率全量微调；记录收敛所需数据量和训练时间。

选择依据：外部测试精度、数据效率、2048×2048 全链路延迟、吞吐、显存和模型大小。foundation 模型不作为默认高速后端，除非实测优势足以覆盖成本。

### 12.6 阶段 E：momia3 集成与统一验收

接口：

- 新模型仍输出通用 `SegmentationResult`，几何结果写入现有 outline/midline/poles/width schema。
- 模型权重、归一化、预处理、decoder 参数和 QC 阈值进入配置及 provenance。
- 保留原版权重、从头训练和新几何后端的统一注册与切换。
- 大图采用分块/批处理时，必须验证跨块实例和 midline 一致性。

验收场景：

- 小图、2048×2048 约 1000 实例、密集接触、长/弯曲细胞、空视野和低对比图像。
- 分割指标、人工几何指标、端到端耗时、峰值显存/内存及失败回退。
- 完整项目测试和真实 pipeline 端到端运行通过后，才标记为可发布后端。

### 12.7 阶段 F：论文证据链

主线建议为“统一细菌实例与解剖几何坐标场”，momia3 为软件和生物学应用载体。

必备结果：

- 多 IoU 阈值的实例分割、接触细胞错误和计数指标。
- 人工真值上的 midline、极点和宽度精度。
- 各模块消融、从头训练与预训练对照、外部数据泛化。
- 网络、实例重建、midline 解码和完整 pipeline 的分阶段速度。
- 至少一个生长、分裂、极点定位或形态测量应用案例。

统计以独立视野/实验批次为单位，报告置信区间，避免把大量像素或同一视野内的细胞当作完全独立重复。

### 12.8 最小可行实施范围

第一轮仅实施：阶段 A 的小型人工几何集、阶段 B 的 top-down 姿态原型，以及阶段 C 的 midline/poles/tangent 辅助场。暂不同时开发 SinkMap、大型 foundation 分支和复杂分枝拓扑。

第一轮评审后再决定：是否投入 ArcField 直接解码、是否采用领域自监督预训练，以及是否用 SinkMap 替代 Euler。这样能以最小成本验证最关键的科学假设，同时保留清晰的退出路径。
