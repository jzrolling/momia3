# momia3

Single-bacterium microscopy image characterization and lineage tracking platform.
Ground-up refactor of MOMIA2: Arrow/Zarr data layer, typed operator registry
(CLI / GUI / MCP schemas), sub-pixel outline and midline extraction, and optional
Omnipose inference.

## Install

    git clone git@github.com:jzrolling/momia3.git
    cd momia3
    pip install -e .
    pip install -e ".[inference]"    # optional: Omnipose-lite inference backend
    pip install -e ".[gui]"          # optional: napari plugin

Python >= 3.11. Core install needs no torch.

## Quick start

    momia3 run examples/pipeline_demo.json          # synthetic end-to-end demo
    momia3 run examples/pipeline_sp003_omnipose.json # real data + Omnipose (weights required)
    momia3 list                                     # registered operations

The pipeline DAG is plain JSON: preprocess -> segment -> measure -> outline ->
midline -> characterize -> track.

## Optional Omnipose inference

momia3.models.omnipose_lite runs the reference Omnipose CPnet weights with a
lightweight orchestration (no RGB flow rendering, torch Euler integration).
Weights are downloaded separately and never bundled:

    from momia3.models.omnipose_lite import FastOmnipose
    fast = FastOmnipose(device="mps")               # resolves ~/.cellpose/models/...
    masks = fast.segment(image)

    result = fast.segment_result(
        image, flow_threshold=0.4, return_flow=True, return_boundary=True
    )

CUDA uses BF16 by default. Input rescaling follows the original SciPy cubic-spline
implementation. Flow-error QC and raw flow/boundary outputs are optional and
disabled by default. Full-image inference is preferred for the current dense-image
benchmarks; tiling is not enabled. Set MOMIA3_OMNIPOSE_WEIGHTS to use another
checkpoint. See docs/omnipose_lite.md.

## Trainable probability-map models

`momia3.models.probability` contains U-Net, AttResUNet and a three-class CPnet
adapter, grouped OmniPose image/mask splitting, three-class target generation,
synchronized augmentation, training and instance-level evaluation. Training
requires torch; no additional training framework is needed.

    python -m momia3.models.probability.train \
      --model unet --data-root /path/to/bact_phase/train_sorted \
      --split-path /path/to/split.json --output-dir /path/to/unet --bf16
    python -m momia3.models.probability.evaluate \
      --checkpoint /path/to/unet/best.pt --data-root /path/to/bact_phase/train_sorted \
      --split-path /path/to/split.json --output /path/to/unet/evaluation.json --tune --bf16

Use `--model attresunet` or `--model cpnet` for the other architectures. CPnet
can additionally use `--pretrained /path/to/bact_phase_omnitorch_0`; only
name/shape-compatible tensors are transferred. For strict holdout benchmarks,
do not use pretrained weights trained on images overlapping the test split. The
split is created once and reused; reconstruction tuning uses only validation data.
At inference:

    from momia3.models.probability import ProbabilitySegmenter
    segmenter = ProbabilitySegmenter("/path/to/unet/best.pt")
    result = segmenter.predict(image)  # SegmentationResult via prob_to_result

ImageJ polygon ROI datasets can be converted with
`momia3.models.probability.rois.prepare_roi_dataset`; the converter performs
closed-spline smoothing, arc-length resampling, duplicate/overlap QC and
OmniPose-compatible mask export.

OmniPose-native field training uses the same checkpoints and split, with
flow/distance/boundary targets generated by the original OmniPose routines:

    python -m momia3.models.probability.omni_train \
      --model attresunet --epochs 4000 --data-root /path/to/expanded \
      --split-path /path/to/split.json --cache-dir /path/to/target_cache \
      --output-dir /path/to/attresunet_omni --bf16

Use `--model cpnet` for the CPnet field model. No pretrained weights are used
unless explicitly requested by the probability-training command. Experimental
DINOv3 dense-feature and hierarchical OmniPose readouts are available in
`momia3.models.probability.dino_omni`; the separate `dinov3` package is not a
core dependency.
